## ☁️ Criar Conta no Azure + Principais Funcionalidades

### Como criar uma conta no Azure

1. Acesse [https://azure.microsoft.com](https://azure.microsoft.com)
2. Clique em **"Comece gratuitamente"**
3. Faça login ou crie uma conta Microsoft
4. Complete as informações solicitadas (inclui verificação com cartão de crédito — **sem cobranças** iniciais)
5. Após criar, você recebe **US$ 200 em créditos grátis por 30 dias**

### 🔧 Melhores funcionalidades do Microsoft Azure

- **💻 Máquinas Virtuais (VMs)**  
  Execute servidores Linux ou Windows com escalabilidade, ideal para desenvolvimento ou produção.

- **🌐 App Services**  
  Hospedagem de aplicativos web com escalonamento automático e integração com repositórios como GitHub.

- **⚙️ Azure Functions (Serverless)**  
  Execute funções sob demanda sem precisar gerenciar infraestrutura — perfeito para APIs e automações.

- **🗃️ Banco de Dados Gerenciados**  
  Serviços como MySQL, PostgreSQL, SQL Server e Cosmos DB com alta disponibilidade e backups automáticos.

- **🚀 Azure DevOps**  
  Solução completa de CI/CD, boards ágeis, repositórios Git e pipelines automatizados.

- **📦 Armazenamento em Nuvem (Blob Storage)**  
  Armazenamento escalável de arquivos, imagens e dados com acesso via API.

- **🧠 Machine Learning e Inteligência Artificial**  
  Treinamento de modelos personalizados e serviços prontos como visão computacional e linguagem natural.

- **🔐 Segurança e Identidade (Azure AD)**  
  Gerenciamento de acessos, autenticação multifator e integração com ambientes corporativos.
